Privacy policy

Applies to LUMEN 0.2.0 and later · Last updated 23 September 2026

The short version: LUMEN collects no personal data, contains no analytics, and has no server to send anything to. It has never asked you to create an account. Everything it stores lives in your own user profile and is deleted when you delete it.

1. Who is responsible

LUMEN is a free, open-source desktop application for Windows, developed and published by Stanislav Miroshnichenko (Unesell Studio), the data controller for the limited processing described below. The complete source code is public at github.com/Stamir36/lumen-gallery, so every claim on this page can be verified rather than trusted.

2. What LUMEN does not do

  • It does not send your photos, videos, filenames, folder names, library statistics or usage data anywhere.
  • It contains no analytics SDK, crash reporter, advertising identifier, attribution framework or update pinger.
  • It does not require or offer an account, sign-in, e-mail address or licence key.
  • It does not read browsing history, other applications' data, clipboard content or your contacts.
  • It does not move, rename, upload or modify your media files. Indexing is read-only.

3. What is stored on your device

LUMEN keeps its own working data in your Windows user profile. None of it leaves your computer and all of it is created by you using the app:

DataLocationWhy
Library database — folder list, file paths, sizes, dates, favourite and recycle-bin flags %APPDATA%\com.unesell.lumen\lumen.db So the gallery does not have to rescan your drive on every launch
Thumbnail cache %LOCALAPPDATA%\com.unesell.lumen\ So the grid appears instantly instead of decoding images again
Log file — may include file paths that failed to decode %LOCALAPPDATA%\com.unesell.lumen\logs\LUMEN.log So a bug report can explain what went wrong
Preferences — language, accent, layout, density, tray behaviour Same database So the app remembers how you like it

Your media files are never copied. The thumbnail cache holds reduced versions of images you have viewed, on your own disk, inside your own user profile.

4. Network activity

A running LUMEN makes no outbound connections on its own. The only network traffic it can produce is caused directly by you:

  • opening a link — for example the project page or a bug tracker — in your default browser, where that site's own privacy policy applies;
  • handing a file to an external player you configured yourself;
  • using the built-in VR dome viewer, which serves images to LUMEN's own WebView over a loopback (127.0.0.1) address. Loopback traffic never reaches the network.

If you installed LUMEN from the Microsoft Store, Microsoft may collect installation and diagnostic telemetry as the store operator, under Microsoft's own privacy statement. That data is not shared with the developer in personally identifying form; the developer receives the same aggregate, anonymised statistics any publisher sees in Partner Center.

5. Files on your computer

LUMEN reads the folders you explicitly add, to build thumbnails and metadata. Removing files from the gallery's view does not delete them; when you ask LUMEN to delete, it moves files to the Windows Recycle Bin through the operating system's API, so they remain recoverable by you. No file outside the folders you selected is accessed.

6. Children

LUMEN is a general-purpose file viewer. It is not directed at children, it collects no data from anyone, and therefore collects no data from children.

7. Your rights

Because the developer holds no personal data about you, there is nothing to request, correct, export or erase on our side. Everything LUMEN stores is under your control:

  • Delete the cache and preferences — remove %LOCALAPPDATA%\com.unesell.lumen\ and %APPDATA%\com.unesell.lumen\, or use the app's own reset options in Settings.
  • Uninstall — through Windows *Apps → Installed apps*, or by running the uninstaller in the install folder. Your media is untouched.
  • Inspect the code — the repository is public and the licence (GPL-3.0) guarantees you can read and rebuild everything.

8. Security

LUMEN runs entirely on your machine and does not transmit data, so there is no data in transit to protect. The application requests only the filesystem permissions it needs for the folders you choose. As with any local software, keeping your Windows account and disk encryption in order is the relevant protection for the data itself.

9. Changes to this policy

If a future version of LUMEN ever introduces a feature that would change this policy — anything that transmits data, however harmless — this page will be updated before that version is released, and the change will be recorded in the project's CHANGELOG. The "last updated" date at the top of this page always reflects the current policy.

10. Contact

Questions about this policy, or about anything LUMEN does with files:

  • Open an issue or a discussion: github.com/Stamir36/lumen-gallery/issues (fastest, and the answer helps other people too).
  • Or write to the developer through the GitHub profile @Stamir36.
